| Shot | What is shown |
|---|---|
| 1 | A Discord call with two popped-out windows |
| 2 | Café opens with one click |
| 3 | Add window for each pop-out |
| 4 | Choosing the output folder |
| 5 | Record all, showing and hiding previews |
| 6 | Stop all and the folder with one file per guest |
| 7 | Live Twitch chat, then Codex answering from the chat Café stored |
| 8 | Codex answering questions about Café over MCP |
| 9 | The main Codex thread and its real history |
| 10 | Repository link and contact |

Codex only reads in this video. Starting a recording from Codex, with or without the optional Confirm click, is not shown because it is not reliable yet. OBS appears only as coming soon unless it works on camera.
